# ESIC Fábrica de IA — Micro-MVP

Solución de IA y automatización para ESIC Medellín: chatbot inteligente (Escenario 1) y
validación automática de documentos (Escenario 2), desplegada en Google Cloud Run.

> Nota: las integraciones con CRM, base de datos académica y sistemas Microsoft son
> **conectores simulados documentados**, no integraciones productivas reales.
